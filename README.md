# NOIR CHESS

A premium responsive chess web app UI with:
- Player vs computer and local 2-player modes
- Easy / Medium / Hard minimax-based computer opponent
- Timers, move history, captures, undo, board flip
- Check/checkmate/stalemate/draw detection via chess.js
- Sound effects and light/noir themes
- Mobile-friendly layout with polished glassmorphism styling

## Run
Open `index.html` in a browser. The chess rules library is loaded from cdnjs, so an internet connection is needed for gameplay unless the library is bundled locally.

## GitHub Pages
Upload the three files (`index.html`, `style.css`, `script.js`) to a GitHub repository and enable Pages from the repository's Settings → Pages.
